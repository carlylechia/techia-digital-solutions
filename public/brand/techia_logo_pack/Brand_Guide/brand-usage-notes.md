# teChia Digital Solutions Logo Pack

This folder contains the separated logo versions requested for teChia Digital Solutions.

## Folder structure

- SVG/ — clean scalable vector files for web, print, editing, and developer handoff.
- PNG/Transparent/ — high-resolution transparent PNG logos.
- PNG/Background/ — ready-to-use dark and light background versions.
- Favicons_App_Icons/ — favicon, app icon, Apple touch icon, Android/PWA sizes, and favicon.ico.
- Social_Profile/ — 1080x1080 social profile versions.
- Brand_Guide/ — quick usage notes, colors, and typography recommendations.

## Font recommendations

Recommended brand fonts:
- Sora
- Space Grotesk
- Inter

The SVG files use a safe font stack: Sora, Space Grotesk, Inter, DejaVu Sans, Arial, sans-serif.
For final production, install Sora or Space Grotesk in your design tool and convert the wordmark to outlines if sending to printers.

## Suggested tagline

## Usage notes

- Use the horizontal logo for website navbars, invoices, email headers, and documents.
- Use the stacked logo for social posts, deck covers, and proposal covers.
- Use the icon-only mark for favicons, app icons, dashboards, and watermarks.
- Use the white logo only on dark backgrounds.
- Do not stretch, recolor randomly, add heavy glow, or place the logo on busy backgrounds without contrast.
